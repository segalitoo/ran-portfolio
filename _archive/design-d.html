01AI side project

Voice tab switching for Chrome

I keep 40 tabs open and lose the one I need. So I built a launcher that listens. Press the hotkey, say part of a tab name, and Chrome jumps there before you finish the word. It also saves tabs by voice, which means it can reopen something you closed last week.

Role
Built by me, solo
Year
2026
Built with
Manifest V3 · Web Speech API · service worker · extension storage
Status
Live, v0.1.5
01
Platform
Chrome extension on Manifest V3, service worker plus a content script injected across all URLs.
02
Voice
Browser speech recognition running locally in the page. Nothing is sent to a server, so there is no API cost and no transcript to store.
03
Matching
Fuzzy match against open tab titles and URLs, so a partial or mispronounced name still resolves.
04
Saved tabs
Tabs saved by voice persist in extension storage, so the command still works after the tab is closed.

02AI side project

Kid-friendly Zoom controls

My kid could not find the mute button in a Zoom class. Zoom is designed for adults in meetings, not seven year olds in lessons. I built an overlay that puts the four controls a child actually needs at a size they can hit, and let them pick a theme so it feels like theirs.

Role
Built by me, solo
Year
2026
Built with
Manifest V3 · content script · scoped to zoom.us
Status
Live, v1.1.0
01
Platform
Chrome extension on Manifest V3. Content script and stylesheet injected into the Zoom web client.
02
Permissions
It requests zero Chrome permissions. Host access is scoped to zoom.us meeting URLs only, which matters when the user is a child.
03
Controls
Reactions, hand raise and mute, mapped to the real Zoom controls underneath and sized for small hands.
04
Themes
Four skins: Classic, Gamer, Space and Candy. Chosen by the kid, remembered between calls.

03AI side project

On-brand ad generator

At Payoneer I watched designers rebuild the same ad in four sizes, over and over. Mint takes a brand kit, a format and a prompt, and returns finished creative with copy already written for the platform. The point is not that it generates images. 04AI side project

Voice typing for Mac

macOS dictation handles English or Hebrew, but I write in both, often in the same sentence. Shhh listens from the menu bar, detects the language as you speak, and pastes the text straight into whatever app is in front. When you stop talking it cleans up the grammar.

Role
Built by me, solo
Year
2026
Built with
Python · Swift menu bar · Google Cloud Speech-to-Text · AppleScript
Status
Live
01
Stack
Python core with a Swift menu bar app on top.
02
Transcription
Google Cloud Speech-to-Text over a streaming gRPC connection, so words appear while you are still talking.
03
Bilingual
English and Hebrew with automatic detection. No mode switch.
04
Insertion
A global hotkey listener captures the shortcut anywhere, and the text is pasted into the frontmost app through AppleScript.

09Design leadership

Icon packages

Icons were being drawn ad hoc for every feature and campaign, so nothing matched. I built one tiered system covering functional UI, illustrative brand and animated icons, all sharing a stroke weight and a set of proportions.

Role
Led by me
Year
2022 – 2025
Scope
Functional, illustrative, animated
Build
Tiered system with usage rules
01
What I inherited
No shared standard. Every new feature or campaign drew its own icons, which fragmented the visual language and bottlenecked delivery.
02
What I decided
Three tiers with explicit usage guidelines, sharing consistent stroke weights, proportions and style so the tiers read as one family.
03
What it produced
A unified language across markets, a faster internal workflow, and assets that scale to new needs without a redraw.
