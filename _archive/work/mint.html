On-brand ad generator

Mint

At Payoneer I watched designers rebuild the same ad in four sizes, over and over. Mint takes a brand kit, a format and a prompt, and returns finished creative with copy already written for the platform. The point is not that it generates images. It is that everything it generates is already on brand.

Stack

React 19 and Vite on the front, Supabase for auth, storage and the generated asset library.

Generation

Google Gemini for both the visual and the platform-specific copy, constrained by the uploaded brand kit.

Rendering

Headless Chrome composites the final artwork, so the output is real layout rather than a model guessing at text.

Formats

Instagram, Facebook, LinkedIn and Stories, generated as a set from one prompt.

Iteration

Every result can be remixed, so a near-miss becomes a starting point instead of a retry.
