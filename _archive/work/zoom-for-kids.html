Kid-friendly Zoom controls

Zoom for Kids

My kid could not find the mute button in a Zoom class. Zoom is designed for adults in meetings, not seven year olds in lessons. I built an overlay that puts the four controls a child actually needs at a size they can hit, and let them pick a theme so it feels like theirs.

Platform

Chrome extension on Manifest V3. Content script and stylesheet injected into the Zoom web client.

Permissions

It requests zero Chrome permissions. Host access is scoped to zoom.us meeting URLs only, which matters when the user is a child.

Controls

Reactions, hand raise and mute, mapped to the real Zoom controls underneath and sized for small hands.

Themes

Four skins: Classic, Gamer, Space and Candy. Chosen by the kid, remembered between calls.
