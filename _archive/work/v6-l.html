Voice tab switching for Chrome

Naymo · designed, built and shipped solo

I keep 40 tabs open and lose the one I need. So I built a launcher that listens. Press the hotkey, say part of a tab name, and Chrome jumps there before you finish the word. It also saves tabs by voice, so it can reopen something you closed last week.

01  /  04
Platform

Chrome extension on Manifest V3, a service worker plus a content script injected across all URLs.

02  /  04
Voice

Speech recognition runs locally in the page. Nothing reaches a server, so there is no API cost and no transcript to store.

03  /  04
Saved tabs

Tabs saved by voice persist in extension storage, so the command still works after the tab is closed.

04  /  04
Languages

Over 10, including Hebrew. Recognition follows the browser language, so no mode switch.
