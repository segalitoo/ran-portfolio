Three ways to hold both orientations.

The same eight projects in all three, with the same mix loaded: three vertical exports and five horizontal, marked on each card so the difference is easy to follow. Only the treatment of the image changes. The grid, the type and the spacing are identical throughout.

Option A · Plinth

One frame for everything, nothing cropped.

Every image is contained inside the same 4:3 well and lifted off it with a soft shadow. A vertical and a horizontal export are both whole, both sit on the same ground, and the grid stays perfectly even. The cost is real: a vertical image ends up about 40 percent smaller on screen than a horizontal one, and the well around it is visible empty space.

Option B · Shelf

No frame. Same height, natural width, one baseline.

Every image is set to the same height and keeps its own width, so they stand on a single line with the rule underneath. Nothing is cropped and nothing is padded out. The ragged top edge is the point: the silhouette tells you what kind of thing each project is before you read a word. Verticals become narrow and tall, which is honest but leaves whitespace to their right.

Option C · Column

One tall frame. The crop is chosen, not accidental.

Commit to a single 4:5 frame and curate what each image shows. Vertical exports fit almost untouched. A horizontal one is cropped hard, so each card declares its own focal point rather than defaulting to the middle. Strongest rhythm of the three and the only one that shows UI at readable size, but you never see a whole screen.
